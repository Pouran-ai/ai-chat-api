# FastAPI AI Chatbot

A simple AI chatbot API built with FastAPI and Python. The project validates user messages, sends requests to an AI service, and returns the assistant's response.

## Features

- FastAPI REST endpoint for chat
- Request validation with Pydantic
- Environment-based API key configuration
- HTTP error handling
- Configurable request timeout

## Technologies

- Python
- FastAPI
- Pydantic
- Requests
- python-dotenv
- Uvicorn

## Requirements

- Python 3.12 or compatible version
- An API key for a supported AI service

## Installation

Clone the repository and open its directory:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_DIRECTORY
```

Create and activate a virtual environment, then install the dependencies:

```bash
python -m venv venv
```

On Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Install the packages:

```bash
python -m pip install -r requirements.txt
```

## Configuration

Create a local file named `key.env` in the project directory:

```env
AVALAI_API_KEY=your_api_key_here
```

Replace the placeholder with your own API key. Never commit `key.env` or publish your API key.

## Running the API

Start the development server:

```bash
python -m uvicorn test:app --reload
```

Open the interactive API documentation:

http://127.0.0.1:8000/docs

## Chat Endpoint

**POST** `/chat`

Example request:

```json
{
  "message": "Hello!"
}
```

Example response:

```json
{
  "reply": "Hello! How can I help you?",
  "status": "success"
}
```

The actual reply is generated by the configured AI service.

## Input Validation

- Messages must contain between 1 and 1000 characters.
- Leading and trailing whitespace is stripped.
- Invalid input is rejected by FastAPI with a validation error.

## Security Notes

- Keep API keys in environment variables.
- Do not commit secret files.
- Use `.gitignore` to exclude local configuration and virtual environments.

## Current Limitations

- Chat history is stored in memory and shared across requests.
- Chat history is lost when the server restarts.
- This project is a learning project and has not been hardened for production use.
