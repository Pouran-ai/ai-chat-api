# AI Chat API

A FastAPI-based chatbot API powered by a locally hosted Qwen model through Ollama.

This project demonstrates how to build an AI chat API using Python, FastAPI, Pydantic, and a local language model.

## Features

- Chat endpoint using FastAPI
- Local AI inference with Ollama and Qwen
- Request validation using Pydantic
- Conversation history
- Non-streaming responses
- HTTP error handling

## Technologies

- Python
- FastAPI
- Pydantic
- Requests
- Uvicorn
- Ollama
- Qwen 2.5 (3B)

## Requirements

- Python 3.12 or compatible version
- Ollama installed and running
- Qwen 2.5 3B model downloaded locally

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Pouran-ai/ai-chat-api.git
cd ai-chat-api
```

### 2. Create and activate a virtual environment

On Windows PowerShell:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3. Install Python dependencies

```powershell
python -m pip install -r requirements.txt
```

### 4. Install and configure Ollama

Download and install Ollama.

GitHub Releases:
https://github.com/ollama/ollama/releases

Make sure Ollama is running.

### 5. Download the Qwen model

Run:

```powershell
ollama pull qwen2.5:3b
```

If the `ollama` command is not recognized in Windows PowerShell, use the full executable path for your installation.

For example:

```powershell
& "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" pull qwen2.5:3b
```

## Chat Endpoint

**POST /chat**

Example request:

```json
{
  "message": "Hello!"
}
```

Example response:

```json
{
  "reply": "Hello! How can I help you?",
  "status": "success"
}
```

The actual reply is generated by the locally running Qwen model.

## Current Limitations

- Conversation history is stored in memory.
- Conversation history is shared across requests in the current implementation.
- Conversation history is lost when the server restarts.
- Responses are non-streaming.
- This project is intended for learning and is not yet production-ready.
